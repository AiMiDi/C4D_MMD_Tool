# 当前场景的 90 Hz 物理对照

日期：2026-10-20。C4D 2027，30 fps 工程，阿芙 2.0：625 根骨骼、479 个刚体、748 个约束、
35 个网格、70,222 个顶点。对同一场景快照比较 120 / 90 / 60 Hz，最终将 C4D 模型运行时设为 90 Hz。
原始场景未修改，发布安装目录未替换；预览使用独立测试宿主及隔离构建。

90 Hz 的整体轨迹偏差比 60 Hz 小，速度收益也较小。它会改变物理结果，不是保持原轨迹的无损优化。
腰部软管和挂件存在局部较大差异，不能从整体统计推断每个位置都比 60 Hz 更接近 120 Hz。

## 性能

同一关闭插桩的实验二进制，按 **120 → 90 → 60 → 60 → 90 → 120** 顺序运行。
每轮重新加载快照，预热第 0 帧和 540–559 帧，再测量 560–619 帧；
每个频率共 120 个计时样本。记录 `ExecutePasses` 的壁钟与调用线程 CPU 时间，
包括场景求值和变形缓存，不包括视口绘制及结果导出。

| 物理频率 | 每个 30 fps 动画帧的子步数 | 整帧计算平均耗时，插桩 OFF | 调用线程 CPU 平均耗时 | Bullet 平均耗时，插桩 ON |
|---|---:|---:|---:|---:|
| 120 Hz | 4 | 59.970 ms | 59.766 ms | 32.153 ms |
| 90 Hz | 3 | 54.697 ms | 53.516 ms | 23.012 ms |
| 60 Hz | 2 | 48.044 ms | 47.266 ms | 16.055 ms |

本轮 90 Hz 相对 120 Hz 的整帧计算耗时低约 **8.8%**，Bullet 阶段低约 **28.4%**；
相对 60 Hz 的整帧计算耗时高约 **13.8%**。阶段数据来自单独的插桩构建，不能与 OFF 整帧数据相减。
后台有其他编译任务，保留了全部原始计时数组；这些结果不是实际视口 FPS，也不证明已达到 60 FPS。

90 Hz 的 Bullet 中，AABB 更新约 6.937 ms，碰撞分发约 5.215 ms，约束求解约 9.511 ms。
这些阶段仍有后续优化价值。下一步可分别测量 AABB 的纯计算与 broadphase 更新，
以及普通单线程依赖构建的 Release 优化选项；本次没有更换多线程世界或依赖编译选项。
之前的多线程与编译选项混杂问题见[上轮验证](../vmd-bullet-controller-performance-20261019/README.md)。

## 效果

每种频率从第 0 帧连续求值到第 619 帧，采集每帧骨骼位置；
在 0、59、119、179、239、299、359、419、479、539、599、619 帧采集全部实际变形顶点及骨骼矩阵。
以下顶点距离均相对本轮 120 Hz，使用网格局部坐标；模型第 0 帧高度约 18.670 单位。

| 频率 | 顶点平均偏差 | 顶点偏差 P95 | P95 / 模型高度 | 最大偏差 |
|---|---:|---:|---:|---:|
| 90 Hz | 0.07464 | 0.31112 | 1.67% | 4.20332，第 479 帧 |
| 60 Hz | 0.19587 | 0.82676 | 4.43% | 3.55034，第 599 帧 |

90 Hz 的平均偏差比 60 Hz 小约 **61.9%**，P95 也明显减小，但最大偏差更大。
第 479 帧的离群点主要位于腰带饰和管道；独立重放到这一帧所得骨骼、顶点与长回放逐字节一致。
实际视口中可见腰部软管和挂件摆动位置不同；所检查的第 479、619 帧未见此前 30 Hz 的大面积裙摆拉长。
这不等于逐帧穿透检测，也不是完整动态视频验收。

所有采样坐标有限。90 Hz 动态骨骼逐帧位移、二阶差分的汇总值没有高于 120 Hz，
但该统计也包含动画驱动，只作为异常变化的辅助检查。
120 / 60 Hz 的全部 620 帧骨骼位置和 12 组网格/矩阵采样与上轮相同频率结果逐字节一致，
排除了场景、输入或实验接口漂移。

## 实现与验收

`source/module/tools/object/mmd_model_runtime.cpp` 的 `ApplyPhysicsConfigToRuntime()` 调用
`physics->SetFPS(90.0f)`，初次创建物理世界及冷重建时均会应用。动画仍按文档帧率推进时间，
求解器、重力逻辑、最大子步数 10 和重置语义保留。通用 libMMD 默认值未改，实验用私有参数没有进入正式代码。

- 插桩 ON / OFF 实验 Release 构建，以及固定 90 Hz、插桩 OFF 的最终 Release 构建成功。
- 最终代码与实验版 90 Hz 在连续播放、跳帧/回退/重复帧、混合前后物理层、全部后物理层、
  关闭物理五组场景中，**112 / 112** 个采样的骨骼矩阵及实际变形顶点逐字节一致。
- 最终固定 90 Hz 完整重放 620 帧，其全部骨骼位置与 12 组网格/矩阵采样同实验 90 Hz 逐字节一致。
- 关闭物理的 13 个采样也与之前 120 Hz 的结果完全一致。
- 实际最终模块通过 `check_profiling_disabled.cmake`；配置为 OFF，模块无 ON 标记。
  即使设置运行时开启环境变量，也没有生成性能日志。
- 所有 C4D 操作通过原生 MCP；未使用电脑操控。最终场景保存在独立测试目录供回放。
