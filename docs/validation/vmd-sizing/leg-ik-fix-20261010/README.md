# 腿部 IK 与约束复核，2026-10-10

本轮修复离线求值缺失 PMX IK 的问题，并新增独立的腿部自碰撞避让。核心测试、真实素材离线扫描和 SDK 2026 Release 编译通过；已有 C4D 播放器完成有限帧对照，仍有姿态误差；**不代表全部穿插已解决，也不代表新版 UI/MCP 已加载验收**。

## 发现与修复

- 旧离线姿态只执行 FK/付与，腿部约束看到的姿态与 C4D 的 IK 播放结果不同。现在通过私有标量桥复用 `MMDIkSolver`，执行 PMX 链限制、变形层和 VMD IK 开关。每次采样重置状态，避免倒序拖帧污染结果；不把 IK 结果写回 FK 旋转。
- 手臂求解器原先没有腿部自碰撞约束。新增 `Options::legAvoidance`，匹配左右 `足` / `ひざ` 的标准静态胶囊或球体，按连续线段最近距离检测；修改标准足 IK 目标的世界 XZ，每只脚上限为平均腿长的 8%。不具备标准双腿 IK 链和碰撞体时给出跳过警告。
- 独立逐帧避让可能切换到另一侧解。增加前帧修正正则项、接触结束后的衰减，以及九帧三角滤波。滤波后重新执行 IK；若该帧最大穿插超过输入值，则回溯减弱或撤销修正。没有硬性保证任意动作的速度/加速度连续。
- 子代理复核发现正数 1–3 次 IK 迭代被提高为 4 次，已改为与 C4D 相同的“正数保留、0 回退为 4”规则并补回归。付与驱动或不可平移的足控制跳过直接烘焙并给出警告。
- 腿部候选及滤波结果不允许脚踝到 IK 目标的误差超过输入误差加容差，避免以目标跟随变差换取碰撞指标改善。
- 地面接触可能覆盖腿部避让。地面修正若增加腿部碰撞深度或 IK 目标误差，则保留落地修正前的脚目标，并用实际脚踝位置报告残差。这意味着冲突时可能留下脚离地；不是完整足底锁定系统。
- IK 控制的手部末端不再写入会被播放覆盖的 FK 接触修正。末尾只有 IK 开关的帧也计入烘焙范围。
- P1 保守预检漏掉 `0x0200` 平移付与标志，已补齐，防止旧位移补偿公式应用到不支持的骨链。
- C4D 增加中英文本“腿部自碰撞避让”，MCP 增加 `leg_avoidance` 布尔选项及进度阶段；沿用同一套 UI/MCP 参数回显和主线程状态栏进度机制。

## 验证结果与边界

- libMMD 两个动作适配 CTest 通过。新增检查覆盖 IK 目标跟随、开关生效、重复采样无历史依赖、IK-only 末帧、非法链、腿部改善与脚位移预算、不烘焙 FK 腿旋转、关闭 IK 后目标不改、取消、时间过滤不增加穿插、接触结束后不残留永久偏移，以及 P1 平移付与预检、低迭代播放契约、不可写足轨道及 IK 目标误差保护。
- MCP Python 测试 42/42 通过，包含协议字段映射。SDK 2026 Release 编译通过。未运行本轮全 SDK 云端矩阵或新版模块加载后的原生 UI/MCP 求解回归。
- 独立候选插件：`output/leg-ik-fix-20261010/plugins/mmdtool/`，含 DLL、真实资源副本和匹配的 MCP adapter。DLL SHA256 见 `summary.json`。当前已加载的插件仍是此前版本，因此现有面板不会凭空出现新开关。
- 第 589 帧深度交叉只部分改善；总计 116 帧还有胶囊超差。有限脚位移、交叉舞步意图和地面目标可能冲突，当前不会无限推开双脚来强行消除碰撞。
- 仍不支持全身/网格级防穿插、无标准腿碰撞体的自动建体、腿与躯干/场景碰撞、动态物理、骨骼 morph、外部父级或场景控制器覆写。手部接触窗口仍按逐帧距离识别，尚非时间一致的接触识别系统。
- 此前记录的“目标绑定模型已改变”应用保护失败，本轮未重测或宣布修复。

## 复验

先构建 libMMD 测试库并运行 CTest，再配置本目录的扫描器。设置 `LIBMMD_LIBRARY` 为当前 Release 静态库，`BULLET_LIBRARY_DIR` 为相同工具链的 Bullet 静态库目录。扫描器调用 `Run`，导出阶段 VMD 和逐帧数据；参数为 UTF-8 三行素材路径文件与新输出目录。模型资产不放入版本库。

```powershell
cmake --build _build_msvc/libmmd-sizing-standalone --config Release --target mmd_motion_sizing_test mmd_motion_sizing_advanced_test
ctest --test-dir _build_msvc/libmmd-sizing-standalone -C Release -R mmd_motion_sizing --output-on-failure
python -m unittest discover -s mcp/tests
```
