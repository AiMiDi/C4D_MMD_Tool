# 全片跨帧候选实验：腿部避让，2026-10-10

结论：在最新 IK 输入与目标跟随守卫下，有限候选的跨帧路径选择能在整片数值上稳定改善现有局部求解结果，且保持位移、修正步长、逐帧穿插和逐脚 IK 残差上界。但它没有逐帧支配现有算法，也没有完成 C4D 视觉、非整数帧或后续地面接触联合验证，仍应保留为后续实验。

本实验未修改共享仓库、未提交、未操作 C4D。`MotionSizing/` 和 `libMMD.lib` 是本次实验冻结的源码/静态库副本；源输入和库的 SHA256 见 `hashes.json`。

## 输入和覆盖范围

- 来源/目标模型与前次验证相同；目标阿芙 2.0，来源 Sour Black.pmx，来源模型仍未获得动作作者确认。
- 输入使用主代理最新 `leg-reviewed-results/all/stage-4.vmd`，即避让前的适配动作。
- 覆盖全部 **1719 个整数帧（0–1718）**。
- 对照使用最新守卫版本的 `leg-reviewed-results/legs/stage-5.vmd`，即含避让但未经过后续接触的结果。
- 本实验只测试腿部避让阶段。不会把此处 329 对×帧的输入统计与后续地面接触版本的 330 混用。
- 所有帧两个足 IK 都启用；未以本素材证明开关跨帧的行为。

## 方法与约束

每帧生成零偏移，以及 64 个平面方向 × 5 个半径，共 321 个候选。左右脚采用相反的 XZ 修正，共求值 551,799 个候选；Y 不变。它只是完整四维双脚平面修正空间的对称子集，并非全局搜索。

候选需同时满足：

1. 每只脚位移不超过平均腿长 8%，即 0.752697449 PMX 单位。
2. 最大胶囊穿插不超过同帧原输入。
3. 每只脚踝到足 IK 目标的残差不超过同帧输入值 + 0.01。

动态规划在全片选择路径，代价包含穿插平方和、位移正则和相邻帧修正变化。额外限制每只脚的修正变化不超过 0.25 PMX 单位/帧，末帧回归零修正。没有对任意加速度设置硬上限。

候选生成约 41.01 秒，Python 路径选择约 1.7 秒。此值来自当前混合工作负载，不是隔离性能基准；若产品化，需要更小窗口/候选集、并行或缓存，不能把此实验速度视为现有交互求解性能。

## VMD 烘焙和读取复验

选择的路径已烘焙到 `temporal-prototype.vmd`，再通过 libMMD 重新读取并评估所有 1719 帧，验证浮点写入没有破坏约束。最终读取数据：

| 检查 | 最大值 |
| --- | ---: |
| 比输入增加的穿插 | 0 |
| 比输入增加的逐脚 IK 目标残差 | 0.009769445 |
| 单脚位移 | 0.752697831 |
| 足 IK 目标 Y 变化 | 0 |
| 单帧脚目标修正变化 | 0.248384902 |
| 单帧膝位置修正变化 | 0.301478680 |

单脚位移与理论预算的约 3.8e-7 差异来自 VMD 浮点写入/求值，复验使用 2e-5 的浮点容差。烘焙前的最大脚目标修正二阶差分为 0.306467427，表明步长限制不等同于加速度连续保证。

注意：`temporal-prototype.vmd` 以 **stage 4 为基底，只加入这次腿部路径**；它不包含后续手臂/手腕/手指/地面接触修正，不能作为本轮最终产品 VMD 发布。它适合后续检查腿部路径本身。

## 仍需验证

- 原型未进入生产源码或发布包，没有 C4D 截图或实际播放验收。
- 没有验证非整数帧，尤其动画曲线插值后的脚/膝运动和碰撞。
- 未与后续地面接触/手部阶段联合求解或再次全片验证；后续阶段可能改变脚目标。
- 路径只使用对称双脚修正，可能漏掉更合适的单脚或非对称解。
- 未加入足底方向、脚尖方向和步态意图约束。每脚目标残差相对输入不恶化，并不代表原本存在的 IK 残差被完全解决。
- 仍有 92 帧胶囊超差，不能描述成完全防穿插。
- 仍需把候选阶段改成接触时间窗口、减少候选，并针对速度/加速度、足底锁定和同一接触分支进行优化。
