## 修正内容

**高位手部目标在保护上限附近跳变。** 旧回溯只试 `1, 0.5, 0.25…`。一帧完整求解略超腕部掌向补偿的 30° 预算，就退到半步；下一帧完整求解合法，立即跳回整步。找到安全步后，现在对拒绝／接受区间做最多 12 次细化，所有候选继续检查掌向、局部旋转预算、逐样本碰撞与加权目标误差，且误差不得高于当前接受结果。没有放宽保护，也没有新增隐藏的跨帧手部状态。

61 帧高位 floor 回归中，第 14→15 帧腕位移 `0.403499 → 0.089320` PMX，整段最大相邻腕位移 `0.403499 → 0.128435`。每帧目标误差均不高于旧结果和输入；手指旋转、掌向及 30° 预算通过。负向控制使用冻结的第一轮 Constraints，能稳定检出此跳变。详见 [手部复核](hand-review.md)、[精确数据](hand-metrics.json)。

**腿部最大穿插改善掩盖另一个碰撞对恶化。** 所有 warm、DLS、方向候选和过滤后输出现在同时保护每个左右腿胶囊对及最大深度。第 589 帧旧结果最大深度较小，但另一对恶化约 `0.11994` PMX；新结果拒绝这种交换。

**局部求解停滞及过滤后突跳。** 停滞时增加有限的确定水平方向候选；过滤阶段同时比较当帧 raw、过滤结果、上一帧实际写出的修正及精确逐脚释放步。候选变化以每足移动预算的四分之一限幅，大于一步的修正还检查最多四帧的安全释放路径。位移仍叠加于当帧原动作，而不是冻结上一帧脚位置。首帧没有历史限幅，IK 关闭仍立即生效。

真实动作 1719 帧及 97 帧窗口／IK 切换探针中，旧实现有 12 项失败，新实现为 0；整段逐碰撞对、IK、平面高度和 8% 位移预算通过。附加腿部修正最大单帧变化 `0.333182 → 0.188174` PMX，第 1244 帧安全前驱候选消除了突跳。逐帧最大深度的累计值 `39.1370 → 28.6298`，但峰值并非下降：588–589 帧提前释放，589 保留输入深度 `1.196935`。这是保护更严格的代价，不能称为所有帧穿插更小。详见 [腿部回执](leg-implementation.json)、[前](leg-before.tsv)／[后](leg-after.tsv)完整数据。
