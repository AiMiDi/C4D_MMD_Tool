## 已复现并修正

1. **接触阈值启停跳变。** 来源动作平滑越过接触距离时，旧求解器立即撤销整次修正。默认 0.3 PMX 阈值附近的微小抖动，用例输入每帧腕位移仅 `0.0000114533` PMX，旧输出跳 `0.785515` PMX。阈值最后 20% 改为渐进影响，接触图使用输入姿态锚定和成对相对偏移。修正后该例保持输入位移量；普通退出过程的最大步长仍有 `0.122199` PMX，因此不宣称恒速或全局连续。
2. **共享手腕的强弱约束混合。** 首轮加权图仍把新弱指尖等权加入腕目标，造成强目标被稀释。最终私有 `ContactTarget` 将置信度贯穿图目标、共享腕加权平均、误差验收、floor 混合与批量路径。强 wrist／finger 加弱 finger 的单角色例由约 `0.400386` PMX 跳变降至 `0.000000197215` PMX；批量及弱 floor 例也通过。手指弯曲、手掌朝向、30° 修正上限及碰撞保护继续保留。
3. **多角色预览时间范围被最后导入覆盖。** 预览统一汇总每个成员的原始／当前阶段骨骼、表情、IK 末帧及当前相机末帧，再设置整个文档及循环范围；交换成员顺序不再截断长动作，切换阶段保留播放位置。
4. **面板重开时默认显示与保留队列不一致。** `InitValues()` 现在按队列选中的最后一项恢复路径、模型、动作槽和完整选项；MCP 状态同步随后仍具有优先权。这项经过源码复核和 SDK 编译，本轮没有另外自动操作本地队列窗口验收。

足部贴地也采用渐进目标，并在完整位移违反原 IK／腿部碰撞保护时尝试有界较小位移。每个候选使用相同保护条件，没有放宽容差。

## 完整真实动作扫描

素材为用户提供的 Sour → 阿芙 / Stay Tonight，场景倍率 8.5；来源 PMX 是否为动作作者原模型没有独立确认。离线扫描 0–1718 全部 1719 帧，比较 wrist、all、all-leg 三组，冻结 `577c46d` 的约束源码作为本轮对照。两个探针使用相同的其余求解实现，避免把其他 IK 改动混入对比。

扭转／避让阶段 VMD 在前后对照中逐字节一致。最终接触阶段手指局部旋转增量为 0，手掌世界朝向增量约 `0.00000831°`，最大关节增量约 `18.38°`，未超过 30°。全选项下额外腕修正的最大单帧变化由 `0.408784` 降至 `0.285262` PMX；这是相对输入阶段的修正变化，不能当作整个手部的速度。

全选项的腕／肘点违规计数仍为 5、最大深度不变；内部臂段样本计数从 1108 变为 1110，残留穿插没有全部解决。仅开 wrist 没有启用避让，其点违规计数从 214 变为 218，也不能把所有指标说成单调改善。软目标改变了诊断目标，因此 unresolved 数量不是等价接触质量指标。完整数据在 [real-comparison.json](real-comparison.json)。
