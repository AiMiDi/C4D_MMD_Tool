# 动作适配后续修复，2026-10-10

本轮后续修改保存在 `codex/sizing-final-fixes` 和 libMMD 的 `codex/motion-sizing-final-fixes`。用户要求先完成修复，等“评估PMX模型一键绑定兼容性”一起完成后统一发布；Package run `38042164707` 已取消，未创建 0.9.3.4 Release。

## 已实现

| 问题 | 修复 |
| --- | --- |
| 相同 PMX 绑定被误判已改变 | 绑定签名只读取 PMX 有效影响骨与语义权重；不再读取 BDEF1/2/SDEF 的未使用存储槽 |
| 顶点去重受未初始化数据影响 | 顶点字段显式默认初始化；去重键按有效影响及隐式权重计算 |
| IK 编辑没有触发结果过期 | 签名补入变形层、IK 目标、迭代次数、单步角度和链限制 |
| 快照漏用正常导出准备流程 | 在隔离克隆中调用 `PreparePMXExportState`，提交编辑绑定并清除表情形变后导出 |
| 足尖参考漏掉 BDEF2/SDEF 第二影响骨 | 使用 `1-w0` 的隐式权重判断，不读取未存储的第二槽 |
| QDEF 权重读写越界 | 将错误的 `0,1,3,4` 索引修正为 `0..3` |
| C4D IK 迭代修改输入局部矩阵 | `SetGlobalTransform` 只更新全局缓存；物理阶段保留显式 `SyncLocalTransformFromGlobal` |

绑定签名的无 SDK 复现显示：仅改变未使用权重槽时，PMX 文件序列化字节完全相同，旧签名却不同。这个机制能真实触发错误过期，但历史现场未保存前后签名，不能称为那次失败的唯一根因。详见 `signature-repro.txt`。

IK 节点契约复核显示：libMMD 的缓存更新只写 global，而 C4D 旧适配器还反算 local。模拟这个副作用能大幅复现旧播放器的膝位置差异。生产修改消除副作用；不通过提高迭代次数、复制副作用或硬编码 8.5 来贴合旧结果。物理写回在所有 `ReflectGlobalTransform` 后已有显式同步，见 [复核报告](native-gap-investigation.md)。
