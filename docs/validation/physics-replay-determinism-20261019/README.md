# 物理严格回放修复：2026 / 2027 原生验证

2026-10-19，在 Sour Black PMX + Stay Tonight 动作、30 fps、0–60 帧窗口内，修复后两代宿主的三项严格回放比较均通过，最大骨骼矩阵分量差和末帧顶点坐标差均为 **0**。阈值仍为 `1e-4`。

这是该用例的修复验收，不代表任意模型、长动画、渲染分段或不同机器上的物理模拟均已获得确定性保证。

## 原因与修改

修复前，两代宿主在跳回开头重放及末帧存档重开后重放中，均出现 `0.045868372625538195` 的最大骨骼矩阵分量差、`0.008281679299009248` 的末帧顶点最大坐标差。原始失败记录保留在 [2026 / 2027 对照](../c4d-2026-2027-compare-20261019/README.md)。

现场捕获发现，跳回第 0 帧后的几何姿态几乎相同，但骨骼的欧拉角表示与初次播放不同。例如右足 IK 的 `-3.1299996076711607` 与 `3.1531856995084255` 相差一整圈。`SetRelMl()` 根据对象先前旋转选择等价角度，再构造矩阵时留下微小舍入差异；部分接近零的分量即使转为 float32 仍不同。Bullet 随后会放大这些输入差异，重建物理世界本身不能消除它们。

原生 API 对照实验对同一批 319 个相对矩阵分别设置零旋转和整圈旋转历史，再写入相同矩阵：旧写法的最大差为 `1.970645868709653e-15`，269 根骨骼有 float32 分量差；不依赖先前角度的分解写法差为 0。参见 [API 对照记录](matrix-history-probe.json) 和 [原始欧拉角观测](baseline-euler-probe.json)。这一实验使用相同宿主内的 C4D API，独立于前后构建中其他并行改动。

修复位于 `source/module/tools/tag/mmd_bone.cpp` 的 `ApplyPlaybackRelativeMatrix()`：对运行时的刚性相对姿态，分别写入平移、`MatrixToHPB(matrix, object->GetRotationOrder())` 和单位相对缩放。动画、静态姿态和求解后的 IK 写回三处统一使用它，保留冻结绑定变换及既有 Bullet 冷重置流程。没有修改物理参数、求解次数、比较门槛或失败分类。

本机 Rider 只打开了其他工程，无法对本仓库建立原生调试会话；本轮依据真实 C4D 运行值和受控实验定位，没有原生断点／暂停栈证据。
