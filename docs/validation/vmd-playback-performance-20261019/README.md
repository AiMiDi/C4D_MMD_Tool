# VMD 物理播放：空层同步与执行计划复用验证

日期：2026-10-19。

两项优化已实现并通过 Cinema 4D 2027 Release 实机效果对比。当前测量没有建立稳定、可归因的端到端提速结论；不能据此声称已经解决播放卡顿。

## 改动

- `MMDModelManagerObject::Execute` 在一次模型求值开始时检查执行计划，物理前后两个分层阶段复用该结果。没有按帧号缓存，保留同帧重新求值时的检查。
- `RunLayeredBonePass` 跳过没有动画骨骼的物理后层；这些层也没有该阶段的 IK。物理前空层仍保留原来的同步与控制器流程，以兼容控制器拥有物理后骨骼、以及所有骨骼都在物理后变形的模型。
- 当前场景的 3 个物理后层都为空，因此每次执行两个分层阶段时，消除了原来物理后阶段的 3 次全骨架同步。其他物理与 IK 同步仍保留。
- Bullet 的步长、子步数、求解参数、重置逻辑、刚体写回和蒙皮脏标记逻辑没有修改。

另一任务的矩阵写回修复已经包含在基线和优化版的同一份 `mmd_bone.cpp` 中，之后提交为 `5ab8e3a1`。本次没有把该修复的效果计入这两项优化。相关独立证据见 [物理回放确定性报告](../physics-replay-determinism-20261019/README.md)。
