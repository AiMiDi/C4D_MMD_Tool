# Proposal

## Why

现有控制器的主要/全部显示粒度过粗，手动动画时难以分清身体部位、FK/IK 和内部辅助输入。需要将用途形态、选择隔离及姿势匹配组成一套可操作的动画工作流。

## What Changes

- 增加根、躯干、面部、左右手臂、左右腿、手指和辅助显示开关，以及部位独显。
- 增加 MMD 调整、IK 动画、FK 摆姿三种预设；左右手臂和腿有明确的 Auto/FK/IK 控制权。
- 为标准手臂生成 IK 手部目标和弯曲方向控制，标准腿增加膝盖方向；显式 IK 在动画层之后解算，Auto 和脚尖保留原 PMX IK。
- 补齐标准手指控制；中心、沟槽、腿 IK 父级、脚尖 IK 使用清晰的用途轮廓。
- 增加重置选中输入、为选中控制器写入关键帧；保留已有冻结坐标、轨道与外部链接。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `motion-vmd-motion`: 控制器动画工作流、分组和明确的 FK/IK 控制权。

## Impact

模型属性、骨骼控制工具、动画求值入口和原生验证。新参数与链接随场景保存；缺失参数使用兼容默认值，不修改依赖子模块。资料和截图只留本地。
