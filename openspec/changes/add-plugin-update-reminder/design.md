# Design

## Context

项目通过 GitHub 发布，支持多个 C4D SDK，且打包流程能够复用已有二进制。现有工具参数写在插件资源目录，不能用于需要跨安装保留的提醒偏好。

## Goals / Non-Goals

目标：后台联网、主线程 UI/偏好读写、四段版本比较、关闭或忽略后稳定生效。
范围外：自动下载安装、预发布通道、修改用户场景。

## Decisions

- 使用 SDK 的 HTTPS Url/InputStream，不增加第三方网络库；保留默认 TLS 证书校验。R20 缺少现代 JSON parser，因此使用独立、深度和大小受限的 JSON 投影读取器，结构化读取根对象版本及通道标志。请求仅指向固定项目 API，页面地址由通过验证的版本构造。
- 单个后台 worker，设置连接/会话超时、响应大小限制、读取总期限，退出时取消并 join。主线程定时轮询结果，不在 worker 操作 UI 或用户设置。
- 提醒设置位于 C4D 首选项的 MMD Tools 分类。启动只后台检查，不展示信息；面板打开、动作适配打开、导入导出调用设置使用标志。主线程 MessageData 定时轮询在使用后弹出非模态新版本说明；同一版本每会话最多自动弹出一次，稍后留待下次会话，忽略跨重启生效。自动检查默认开启，间隔 24 小时；失败也记录尝试时间。手动检查绕过间隔和忽略设置，但不重复启动 worker。
- GitHub `body` 与版本一起缓存；按当前资源语言标志选择 `## 中文` 或 `## English` 段落，保留小标题和列表，排除另一语言和构建元数据。缺少当前语言时显示相应语言的发布页引导，不自动翻译或混合语言。无分段旧说明按原文显示。
- 使用项目原有未注册预留 ID 1056725 注册首选项、1056721 注册消息插件。更新弹窗为工具命令的 subid 2，不增加临时生产 ID。
- GetWorldPluginData/SetWorldPluginData 保存开关、忽略版本、上次请求时间和最新版本缓存。保留同 ID 容器其他数据。
- `res/cmt_version.txt` 保存安装版本，打包时按包版本覆盖，兼容复用二进制。版本缺失/无效时显示未知并不判定更新。
- 纯 C++ 逻辑单独测试比较、节流、忽略与 GitHub 的嵌套 JSON 解析。

## Risks / Trade-offs

- GitHub 受网络或限流影响：失败显示可重试的状态，保留已知更新缓存；请求失败本身不触发弹窗，使用工具时仍可提醒缓存中已知的新版本。
- 旧 SDK 网络/解析 API 差异：检查 SDK 头文件并独立编译旧 SDK，差异集中在兼容层。
- 版本文件需维护：发布打包时写入最终版本，开发版本随发布日志更新；文档明确说明。
