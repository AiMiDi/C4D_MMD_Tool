# Proposal

## Why

用户目前需要主动访问发布页才能发现插件更新。需要一个不阻塞建模或动画工作的更新提醒，同时保留用户对联网检查和提醒频率的控制。

## What Changes

- 插件启动时后台检查 GitHub 最新正式版，每 24 小时最多自动请求一次。
- C4D 首选项的 MMD Tools 分类提供自动检查开关、版本状态、手动检查及发布页入口。
- 使用 MMD Tools 面板、动作适配、导入导出功能时才弹出新版本说明；按当前界面语言选择中文或英文段落，提供查看更新、稍后及忽略当前版本。
- 采用三段或四段数字版本比较；预发布、无效响应、旧版本不产生更新提醒。
- 提醒偏好和缓存保存在 C4D 用户设置；发布包携带可被打包流程更新的版本文件。

## Capabilities

### New Capabilities

- `plugin-update-reminder`: 正式版更新检查、非模态提醒及用户偏好持久化。

### Modified Capabilities

无。

## Impact

涉及插件生命周期、工具面板、双语资源、共享网络框架依赖、发布包版本标记、独立逻辑测试。无需下载或安装插件，也不改动场景。
