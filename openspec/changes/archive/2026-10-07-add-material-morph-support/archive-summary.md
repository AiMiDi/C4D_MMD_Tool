# PMX material morph baseline

Archived on 2026-10-07 after all planned tasks and artifacts were complete. Delta specs were synchronized into the main specifications.

Adds editable and persistent PMX material morph offsets, import/export round trips, effective-strength composition, and generic Standard texture wrappers. The baseline implementation was committed as a99c9c2a; newer shader bindings, RS Toon and Matcap work remain separate active changes.

This archival commit contains specifications and records only. Shared implementation edits for active proposals remain in the working tree.
