# Design

## Context

阿芙模型现有生成资格产生 24 个控制器。圆环世界半径约 4，袖口处大多只露出很短的一段。单纯放大能改善轮廓，仍需遮挡提示和辅助过滤。

## Goals / Non-Goals

提高可见性和辨识度，提供模型级统一管理，并补齐腿脚和已有 MMD IK 的操作入口。保留原有局部轴/固定轴控制器、兄弟层级、旋转轴及增量语义；不新建或重绑 IK 解算器，不改变蒙皮或绑定姿态。

## Decisions

- 使用骨架的模型空间跨度、层级深度和骨骼功能决定半径，统一整体尺寸倍率。只缩放 spline 点，不缩放对象变换；继承旋转的细调控制器缩小。
- 圆环表示旋转，紧凑菱形表示固定轴，圆角框表示位移；小轴向标记在侧面仍能辨认，几何不依赖视口方向。
- 左青蓝、右珊瑚红、中间暖金。隐藏/禁用的 PMX 骨归为辅助，默认常用过滤。
- 使用完整日文/英文标准骨名匹配腿、膝、脚踝、脚尖、足先 EX 和 IK 父级，不用子串猜测衣物骨或 D 变形骨。IK 目标以 PMX 的 IS_IK 标志为准，名字本身不创建伪 IK。
- FK 使用逐级缩小的圆环；足 IK 使用水平脚形框、脚尖 IK 使用小三角、IK 父级使用较大圆角框。继续沿用原始 IK 链和动画输入。
- 控制器空间换算以本帧动画基准为准，同帧修改清除旧 IK 缓存；FK 登记沿用持久化 authored-pose 标记，并允许继续叠加调整。
- IK 链受影响的非目标骨存在有效 FK 控制器旋转时，该链让出本帧旋转所有权；控制器归零后重新求解。目标平移仍正常进入 IK。
- BoneManager 的 XRAY 绘制阶段绘制连续穿透轮廓，细深色底线保证在衣服和皮肤上的对比度，选中时加粗提亮；保留真实 spline 几何和 C4D 原生选取。用户实测反馈袖口的淡虚线仍难看清，因此默认改为连续轮廓，提供关闭开关。
- 模型参数集中控制显示、尺寸、遮挡提示；生成/刷新与选中可见对象为按钮。现有骨骼管理入口仍可用，隐藏状态相互同步。
- 单独的视觉刷新路径只改 spline 点、颜色和可见性，不重新冻结或清零已有控制器；创建时才初始化坐标。

## Risks / Trade-offs

遮挡提示不能代替原生选取逻辑，需要在 C4D 中检查可见与可选轮廓。新参数用未占用编号，旧场景缺失时使用默认值；跨 SDK 资源同步。整体尺寸来自 bind 数据，避免播放中呼吸式缩放。

## Validation

同一原生视口保存前后效果。验证常用/全部/隐藏、尺寸、选中、保存重开、撤销、旧控制器升级、关键帧/绑定保持及动画驱动。SDK 2026 / R20 Release 编译，2026 原生验证，并回归上一项 PSR 修复。
