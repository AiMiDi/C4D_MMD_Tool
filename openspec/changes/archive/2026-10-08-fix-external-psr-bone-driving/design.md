# Design

## Context

见 proposal.md。ModelManager 在 Expression 0 执行完整骨骼流程；原生 PSR 同属 Expression 阶段。复现证据位于 output/afu-psr-20261008-61032，涉及早执行被覆盖和晚执行不参与 IK 两种故障。

## Goals / Non-Goals

目标是在不修改用户约束、骨架和绑定矩阵的前提下，支持普通空对象的 PSR 位置/旋转驱动。该变更不实现新 Rig、自动绑定、全身 IK/FK 或非 Expression 阶段的任意第三方表达式。PMX 无骨骼缩放动画语义，缩放不作为 MMD 求解输入。

## Decisions

1. 有有效 PSR 输入的模型采用三段调度：Expression -500 准备 MMD 动画基线；原生 Expression 约束正常执行；Expression +500 捕获受约束通道，再运行 MMD 分层动画、继承、IK 和物理。无外部约束时保留 Expression 0 的求解路径。
2. 输入使用骨骼局部相对矩阵，保留 frozen 绑定矩阵。仅受约束的位置/旋转通道在分层求值时被替换，继承源的缓存与写入场景的姿态保持一致。约束混合、轴掩码和偏移由 C4D 原生标签求值。
3. 每次早阶段清除前轮外部样本和 IK/append 临时 override；保留既有 VPD 临时姿态。禁用/删除约束也触发一次重算，避免同帧残留。CopyTo、Read、runtime reset 不复制样本。
4. BoneManager 的普通中间写回在外部求值模式下跳过，避免在原生约束与后阶段捕获之间覆盖输入。物理只在后阶段推进一次，同帧仅反映已有物理状态。

## Risks / Trade-offs

- 有约束模型会额外准备一次动画基线并在同帧执行必要求解；通过原生对照和重复求值检查累计漂移。
- 约束直接驱动 IK 链内骨骼与 MMD IK 存在所有权冲突；显式旋转驱动链内骨骼时该链不再由 MMD IK 覆盖，单纯驱动 IK 目标不禁用求解。
- 原生约束可以依赖其他表达式；本变更支持 Expression 范围，跨模型循环驱动不属于此修复的验收范围。
- 动态物理骨骼保留现有物理最终写回规则；外部姿态作为物理输入，不额外推进仿真。

## Migration Plan

无需场景格式迁移，替换插件后二次打开现有复现场景即可验证。回退原插件恢复原调度，场景约束和权重保持原样。
